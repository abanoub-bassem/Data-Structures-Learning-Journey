# C++ Data Structures Practice

## About

This repository contains my personal practice and implementations of different Data Structures using C++. 

It is part of my learning journey in understanding Data Structures and improving my problem-solving and programming skills. This is not a commercial project, but a collection of exercises and implementations created while studying and practicing.

## Topics Covered

### Linked List
- Creating and managing nodes.
- Inserting elements (First, Last, Before).
- Deleting elements (By value, Even numbers, Nth node, and conditional removals).
- Searching for elements.
- Reversing a Linked List.
- Finding the middle element.
- Removing duplicate elements.
- Finding minimum and maximum values.
- Recursive operations (Sum and Multiplication).

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- Pointers
- Recursion
